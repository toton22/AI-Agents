How to read it

The first seven branches answer "what do I build with?" They run roughly from least to most engineering. Branch 1 needs a browser and an afternoon. Branch 6 needs Python and a willingness to read error messages.

Branches 8 to 11 cut across all of them. Whatever tool you pick, you're still assembling a model, instructions, tools, knowledge, memory and guardrails (branch 8). You'll still need to connect to company systems, ideally through a standard like MCP (branch 9). You'll still choose an arrangement, from one agent with tools up to a team of agents (branch 10). And you'll still put it somewhere people can reach it (branch 11).

That's the reason the course is split into modules and method pages. The modules teach branch 8 to 11 once. The method pages show how each tool in branches 1 to 7 implements them.
